# Example engine requests

Complete, valid request bodies served as `quantra://examples` resources and
through the `list_examples` / `get_example` tools. `INDEX.json` is the catalog
(one row per example: name, category, endpoint, title, description, the
QuantLib reference value and a machine-checkable `oracle` when the engine's
own suite asserts one, `expected_status`); it is generated by
`scripts/pin_engine.py` together with the files below. Do not edit any of them
by hand; re-run the pin script to bump.

## The engine's fixtures (`<category>/<name>.json`, 221 files)

Copied verbatim from `examples/data/**/*.json` of the
[Quantra pricing engine](https://github.com/joseprupi/quantraserver) at the
pinned tag (`src/quantra_mcp/schema/PIN`). Categories are the engine's own
folders (`ir_swaps`, `bonds`, `swaption`, `cds`, `fra`, `cap_floor`, `equity`,
`inflation`, `inflation_cap_floor`, `curves`, `calendar`, `vol`,
`callable_bonds`, `zero_coupon_swap`); the fixtures that sit directly under
`examples/data/` are filed under `misc`.

192 of them are the cases of the engine's functional parity catalog
(`tests/functional/manifest.py` + `CATALOG.md`, vendored as
`quantra://docs/engine-catalog`): each is POSTed to the engine in its own test
suite and the answer is asserted against an independent QuantLib reference
(NPVs within 0.01, curve and vol series within 1e-9, calendar dates exactly,
calibration parameters within 1e-7). The index carries that reference value
(`reference_text`, `reference_value`) and its tolerance (`oracle`). The
other 29 are uncataloged examples (endpoint found by validating the body
against every request schema; it must match exactly one). One of them,
`fixed_rate_bond_beyond_pillar_request`, is the engine's own error fixture and
is expected to return 422 (`expected_status`, `why`).

## The blog examples (top level, category `blog`)

| Name | Endpoint | Source |
|---|---|---|
| `sofr-bootstrap-request` | `POST /bootstrap-curves` | https://quantra.io/blog/bootstrapping-a-sofr-curve (downloadable request JSON, `/blog/data/sofr-bootstrap-request.json`) |
| `sofr-ois-swap-request` | `POST /price-ois-swap` | same post, `/blog/data/sofr-ois-swap-request.json` |

Both come from the Quantra blog post *Bootstrapping a SOFR curve* (2026-08-03),
where they were run verbatim against the public engine (`https://api.quantra.io`,
engine 0.6.0) and checked against QuantLib-python 1.41: the OIS swap prices to
NPV `337986.7913...` and the bootstrap's 50Y discount factor is
`0.262755579831`. They are copied byte-for-byte; do not edit them here.
